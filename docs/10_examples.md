# Examples (示例)

Run the example in `main.go` (运行 `main.go` 中的示例):

```bash
go run main.go
```

Output:

```
true
```

This demonstrates that maps are not reference types; reassigning the map inside a function does not affect the caller's map variable. (这演示了map不是引用类型；在函数内重新分配map不会影响调用者的map变量)
